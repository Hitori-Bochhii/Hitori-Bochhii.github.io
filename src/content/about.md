# About This Site

本博客基于 [Twilight](https://github.com/Spr-Aachen/Twilight) 主题构建，使用 [Astro](https://astro.build) 静态站点生成框架。

::github{repo="Spr-Aachen/Twilight"}

## Framework

- **框架**: [Astro](https://astro.build) — 现代化的静态站点生成器，支持岛屿架构与多框架组件混合
- **主题**: [Twilight](https://github.com/Spr-Aachen/Twilight) — 由 Spr-Aachen 开发的开源博客模板，集成 Decap CMS、粒子特效、音乐播放器等丰富功能
- **部署**: [GitHub Pages](https://pages.github.com/) + GitHub Actions 自动构建
- **包管理**: pnpm
